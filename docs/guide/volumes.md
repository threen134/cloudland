# 云硬盘指南

云硬盘是独立于云服务器生命周期的块存储：删除云服务器时挂着的数据盘会卸下、保留，可以再挂给别的云服务器。

## 系统盘与数据盘

- **系统盘**随云服务器创建，大小由规格决定，云服务器删除时一起删除。
- **数据盘**在「云硬盘」页单独创建，按需挂载、卸载、扩容、删除。云硬盘列表默认只列数据盘。

## 存储池

建云硬盘时选一个存储池（不选就用默认池）。存储池有两类，区别在于**云硬盘能挂到哪里**：

| | 本地池（如内置池 `local`、`local-hdd`） | 共享池（建在 GPFS、Ceph 存储集群上） |
|---|---|---|
| 卷放在 | 某一台计算节点的本地盘上 | 存储集群里（GPFS 文件系统里的文件，或 Ceph 的 RBD 镜像） |
| 第一次挂载前 | 不占任何节点，挂给谁就落在谁所在的节点上 | 建卷时就建好，不属于任何节点 |
| 能挂给 | 落盘之后只能挂给**同一台节点**、且该节点有这个池的云服务器 | **任何一台**这个池可用的节点上的云服务器；卸下后可以换节点再挂，数据不变 |
| 迁移云服务器 | 磁盘随云服务器复制到目标节点 | 不复制，迁移更快，与盘的大小无关 |
| 当系统盘 | 可以 | 暂不支持 |

存储池列表里，共享池的类型列显示「共享 · GPFS」或「共享 · Ceph」。两种共享池用起来一样。

## 创建

「云硬盘」→「创建」，填名称、容量（GB），选存储池。

- 本地池上的卷创建后立即「可用」，第一次挂载时才真正落盘。
- 共享池上的卷先显示「处理中」，几秒内由存储节点建好后变为「可用」；10 分钟还没建好会变为「错误」，可以删除重建。

## 挂载与卸载

在云硬盘列表或详情点「挂载」，选云服务器。不能挂的云服务器在下拉里是灰的，并注明原因（「云硬盘在 work-02 上」：本地卷已落在别的节点；「所在机器没有可用的存储池」：那台节点没有这个池，或共享池在那台节点上当前不可用）。挂载后在云服务器里用 `lsblk` 找到新盘（设备名按虚拟机看到的顺序命名，平台显示的 `vdb` 等只作参考），首次使用要自己分区、建文件系统。

卸载前请先在虚拟机内卸载文件系统（`umount`）。

## 扩容

「扩容」只能变大不能变小。

- 挂在**开着的**云服务器上的卷**在线扩容**，云服务器不重启，虚拟机内立即看到新容量；没挂载或云服务器关机时离线扩容。
- 云服务器正在救援、迁移、重装、调整配置时不能扩容。
- 扩容后要在虚拟机内扩展分区和文件系统，扩容弹窗里有 Linux（`growpart`、`resize2fs`、`xfs_growfs`，含 LVM）与 Windows（磁盘管理 → 扩展卷）的步骤。

## 删除

删除是异步的：卷进入「删除中」，由节点删掉文件后记录才消失。本地卷所在的节点离线时不能删除；30 分钟还没删掉会变为「删除失败」，可以再删一次。挂着的卷要先卸载。

## 状态

| 状态 | 含义 |
|---|---|
| 可用 | 没有挂载，可以挂载、扩容、删除 |
| 已挂载 | 挂在某台云服务器上 |
| 处理中 | 共享池上的卷正在由存储节点建出来 |
| 挂载中 / 卸载中 / 扩容中 | 操作已下发、等节点完成，页面会自动刷新 |
| 删除中 / 删除失败 | 见上面「删除」 |
| 错误 | 节点上的操作失败，详情里有原因 |
| 已丢失 | 所在的本地池被管理员宣告丢失，数据已不可用 |
| 等待接管 | 所在节点被删除时保留了数据盘，等新节点接管后恢复 |
