# 网络与 VPC

## VPC (虚拟私有云)

VPC 为用户提供逻辑隔离的网络环境。

- **多租户隔离**：不同组织的 VPC 互不通信；同一组织的不同 VPC 默认也不通，要互访用中转网关。
- **自定义网段**：支持用户定义 RFC 1918 私有地址空间。

## 子网管理

一个 VPC 包含一个或多个子网。

- **DHCP 支持**：自动为实例分配私有 IP。
- **网关路由**：统一管理跨子网与外部通信。

## 浮动 IP (Floating IP)

用于将私有网络中的实例暴露到公网或指定网段。

1. **绑定/解绑**：可以将 FIP 动态绑定到任何实例网口。
2. **按量付费/限速**：支持对 FIP 进行精细化流量控制。

## 中转网关

把同一组织、同一区域的多个 VPC 接到一起用内网地址互访，默认全互通，也可以用路由表做隔离（中心辐射）、按网段传播、加静态路由与黑洞。转发在各计算节点本地完成，不经集中节点，详见 [中转网关](./transit-gateways.md)。

## VPN 网关

把 VPC 与机房、其他云或个人设备接通：站点到站点用 IPsec（静态路由或 BGP），客户端接入用 WireGuard。每个 VPC 最多一个 VPN 网关，详见 [VPN 网关](./vpn-gateways.md)。
