# 网络与 VPC

## VPC (虚拟私有云)

VPC 为用户提供逻辑隔离的网络环境。

- **多租户隔离**：不同组织的 VPC 互不通信。
- **自定义网段**：支持用户定义 RFC 1918 私有地址空间。

## 子网管理

一个 VPC 包含一个或多个子网。

- **DHCP 支持**：自动为实例分配私有 IP。
- **网关路由**：统一管理跨子网与外部通信。

## 浮动 IP (Floating IP)

用于将私有网络中的实例暴露到公网或指定网段。

1. **绑定/解绑**：可以将 FIP 动态绑定到任何实例网口。
2. **按量付费/限速**：支持对 FIP 进行精细化流量控制。
