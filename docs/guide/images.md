# 镜像管理指南

## 概述

镜像 (Image) 是 CloudLand 创建虚拟机的蓝图，类似于操作系统的安装盘快照。

### 支持格式

| 格式 | 描述 |
|------|------|
| **qcow2** | 默认推荐格式，支持精简配置与快照 |
| **raw** | 原始二进制格式，拥有最高的 IO 吞吐性能 |
| **ISO** | 用于引导安装系统的光盘镜像 |

## 镜像可见性

1. **公共镜像 (Public)**：所有组织与用户均可查看并使用。
2. **组织镜像 (Org Private)**：仅限所属组织内的用户使用，满足私密业务需求。

## 导入镜像

您可以通过 API 或 Dashboard 上传本地文件，或者通过指定 URL 进行远程拉取。
