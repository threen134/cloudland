# 项目简介

## 什么是 CloudLand？

CloudLand 是一个轻量级的 **基础设施即服务 (IaaS)** 框架，用于管理虚拟机实例、软件定义网络 (SDN)、存储卷等云基础设施资源。

它能够在**单个集群中支持超过 10,000 个 Hypervisor 节点**，非常适合作为大规模公有云或私有云环境的基础。

## 核心特性

| 特性 | 描述 |
|------|------|
| 轻量架构 | 最小化组件，简洁高效的设计 |
| 低学习门槛 | 开发者和运维人员都能快速上手 |
| 可靠的节点通信 | 计算节点主动连接控制面，基于 gRPC 双向流下发命令、回传结果，断线自动重连 |
| HPC 级扩展 | 基于高性能计算架构，确保卓越的可扩展性 |
| 自愈稳定 | 自动故障恢复，保障持续运行 |
| 高度可定制 | 易于扩展，满足各种定制需求 |

## 技术栈

```
┌─────────────────────────────────────────────────┐
│           Dashboard (Vue 3 + TypeScript)        │
├─────────────────────────────────────────────────┤
│        中央网关 cpgateway (Go / Gin)             │
│        认证 · 组织 · 配额 · 多 Region 代理        │
├─────────────────────────────────────────────────┤
│           区域 REST API clapi (Go / Gin)        │
├─────────────────────────────────────────────────┤
│           主控 cland (Go / gRPC :5006)          │
├─────────────────────────────────────────────────┤
│        计算节点 agent cloudlet (Go) + Shell      │
├─────────────────────────────────────────────────┤
│  KVM / QEMU · libvirt · Linux bridge + VXLAN    │
│  PostgreSQL                                     │
└─────────────────────────────────────────────────┘
```

控制面容器化交付，计算面裸机部署以保留原生 IO 性能；计算节点上的虚拟机、网络、存储操作由 `scripts/` 下的 Shell 脚本执行，由 cloudlet 经 gRPC 接收并回传结果。
