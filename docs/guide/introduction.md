# 项目简介

## 什么是 CloudLand？

CloudLand 是一个轻量级的 **基础设施即服务 (IaaS)** 框架，用于管理虚拟机实例、软件定义网络 (SDN)、存储卷等云基础设施资源。

它能够在**单个集群中支持超过 10,000 个 Hypervisor 节点**，非常适合作为大规模公有云或私有云环境的基础。

## 核心特性

| 特性 | 描述 |
|------|------|
| 轻量架构 | 最小化组件，简洁高效的设计 |
| 低学习门槛 | 开发者和运维人员都能快速上手 |
| 高性能消息 | 优化的内部消息传递，快速可靠 |
| HPC 级扩展 | 基于高性能计算架构，确保卓越的可扩展性 |
| 自愈稳定 | 自动故障恢复，保障持续运行 |
| 高度可定制 | 易于扩展，满足各种定制需求 |

## 技术栈

CloudLand 采用多语言混合架构：

```
┌─────────────────────────────────────────────────┐
│                   Dashboard (Vue 3 + TypeScript)│
├─────────────────────────────────────────────────┤
│                   REST API (Go / Gin)           │
├─────────────────────────────────────────────────┤
│                   控制面 cland (C++)             │
├─────────────────────────────────────────────────┤
│           SCI 框架 / 计算节点 cloudlet (C++)      │
├─────────────────────────────────────────────────┤
│   KVM / QEMU · Open vSwitch · PostgreSQL        │
└─────────────────────────────────────────────────┘
```
