## C-06b 存储池回到基线

```bash
ssh work-01 'source /root/st-env.sh >/dev/null
api GET /storage_pools | jq -r ".storage_pools[]|\"\(.name) builtin=\(.builtin)\""
P="docker exec cloudland-postgres psql -U postgres -d cloudland -Atc"
$P "select p.name, h.hostid, h.status, h.layout from hyper_storage_pools h join storage_pools p on p.id=h.pool_id order by p.id, h.hostid"
echo "预留: $($P "select count(*) from storage_reservations")"
echo "异常卷: $($P "select count(*) from volumes where status in (\$\$deleting\$\$,\$\$delete_failed\$\$,\$\$lost\$\$,\$\$orphaned\$\$) and deleted_at is null")"
for h in local work-02 work-03; do echo "== $h"
  c="losetup -l -n | wc -l; grep -c storage_allow_loop /opt/cloudland/scripts/cloudrc.local 2>/dev/null; ls /opt/cloudland/pools"
  if [ "$h" = local ]; then sh -c "$c"; else ssh -n root@$h "$c"; fi
done'
```

> 一条 `psql -c` 里放多条语句**只会打印最后一条的结果**，所以上面拆成了多次调用。SQL 里的字符串用 `$$...$$`（经 ssh 再套一层双引号时单引号会打架）。

- [ ] 只有 `local` 与 `local-hdd`，没有 `wp-` 池
- [ ] `local-hdd` 在三台上都是 `ready`、布局 `single`
- [ ] `storage_reservations` 为 **0**（迁移 / 创建失败会留预留，5 分钟兜底任务会清）
- [ ] 没有卡在 `deleting` / `delete_failed` / `lost` / `orphaned` 的卷
- [ ] 各节点没有残留 loop 设备，`cloudrc.local` 里没有 `storage_allow_loop`
- [ ] `/opt/cloudland/pools/` 下只有 `local-hdd` 的目录且已挂载
