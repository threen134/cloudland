## 设计约定（判定预期的依据）

- **任务**：部署、加盘、建池等都是集群上的分步任务。一个集群同时只有一个结构任务（`active_task`）和一个池任务（`active_pool_task`）；占着时其他操作 409（123002）。失败停在出错那一步，重试只重跑失败的节点；节点离线 5 分钟判失败
- **布局规则**（`CheckLayout`，部署和每次增删节点 / 盘都按变更后的集群检查）：仲裁节点奇数且 ≥ 3、管理节点 1–2 个且是仲裁节点、NSD 节点至少一块盘、磁盘至少在 3 台上、数据副本 ≤ 失败组。违反时 400（123021），消息只带一次错误码
- **磁盘识别**（装了 GPFS 的节点）：GPFS 分区类型的盘 `unknown_member`；无签名且盘头 4 MiB 不全为零 `unknown_member`；全零 `free`；集群认领的盘 `gpfs_nsd`。`wipe_disk` 清零两端各 10 MiB
- **共享池**：托管集群上一个独立 fileset `cl_<池 UUID 前 8 位>`，挂在 `/gpfs/<fs>/<fileset>`，池根有 `.cloudland-pool`（`driver=gpfs`、`pool_uuid=`）与 `volumes/ images/ nvram/ tmp/`。有配额时 `df` 显示配额（`--filesetdf`）。每台节点 `/opt/cloudland/run/storage/<集群>/shared_pools.json` 有池清单，`/opt/cloudland/run/pools/<池>.state`（+ `.shared`）是探测结果
- **探测**：心跳每 30 秒拉起 `shared_pool_probe.sh`，查文件系统类型、标记文件、`tmp/` 能否写；变化或每 5 分钟上报 `shared_pool_status`；2 分钟没有新结果判「探测卡住」，结果早于本次开机报「开机后还没检查过」
- **共享卷**：建卷时就由任一池可用的节点落盘（`pending` → `available`），`volumes.hyper` 恒为 0；可挂给任何一台池可用的节点上的云服务器；磁盘 `cache='none' error_policy='stop'`；迁移时不复制、不预留
- **系统盘放共享池**：S2 里一律拒绝（S4 才做）

### ⭐ 最容易误判的几点

- **`gpfs.service` 是 disabled 是正常的**：开机由 `mmautoload.service` 拉起 GPFS
- **重启后的 NSD 是 GPFS 自己拉起的**（`restripeOnDiskFailure`），不能用来证明平台的看护在工作；要验证看护用 SHS-12（手工 `mmchdisk stop`）
- **`mmlsdisk` 不能 `-e` 与 `-Y` 一起用**（报错、输出为空）；机器可读输出一律 `-Y` 再按列过滤
- **部署时看到 work-03 的「下载」已经 92%**：状态是轮询上报的，有几秒延迟；SHS-04 断网不必卡在 0%
- **进 cirros 只能从它所在节点的 VPC 路由器登录**（anycast 网关）；迁移之后要换节点

## 历史缺陷回归点汇总

| # | 现象 | 根因 / 判定 |
|---|---|---|
| 1 | 建集群报 `Host key verification failed` | GPFS 把地址反查成主机名再登录，`known_hosts` 只有地址；改为「地址,主机名」；SHS-03 |
| 2 | 建文件系统失败 | 只传了 NSD 名，`mmcrfs` 要完整描述（用途、失败组、存储池）；SHS-03 |
| 3 | NSD 被当成已存在全部跳过 | `mmlsnsd -d <名字>` 对不存在的也返回 0，改按 `mmlsnsd -X` 的列表比对；SHS-03 / SHS-14 |
| 4 | 删除集群的确认名不生效 | 网关转发 DELETE 丢请求体，改查询参数 `confirm_name` / `purge_packages`；SHS-14 |
| 5 | **成员节点上的新盘永远加不进集群** | 装了 GPFS 的节点上空白盘一律 `unknown_member`；改为按盘头是否全零判（2026-10-02）；SHS-10 setup |
| 6 | 重新均衡必然失败 | `do_rebalance` 取错参数，把输入 JSON 当文件系统名（2026-10-02）；SHS-10 |
| 7 | 集群「已分配」恒为 0 | 前端写死 `:allocated="0"`，后端汇总补 `allocated_bytes`（2026-10-02）；SHS-05 |
| 8 | 布局错误消息里错误码重复 | 包装时用了 `err.Error()`，改取内层消息（2026-10-02）；SHS-11 |
| 9 | **掉线 NSD 的看护从来不拉盘** | `mmlsdisk -e -Y` 是不允许的组合，输出为空（2026-10-03）；SHS-12，WSL `stc-test4.sh` |
