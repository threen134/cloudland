`st-env.sh` 的核心（region uuid 是 work-01 的 `default` 区域，换环境要改）：

```bash
cd /opt/cloudland/deploy/docker
PW=$(grep "^ADMIN_PASSWORD=" .env | cut -d= -f2-)
B=https://127.0.0.1/api/v1
login() {
    T=$(curl -sk -X POST $B/auth/token -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"$PW\"}" | jq -r .access_token)
    T=$(curl -sk -X POST $B/auth/switch-region -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d '{"region":"49fce7f0-0ae3-49e1-8ffb-02c816b26bb1"}' | jq -r .access_token)
}
BODY=/tmp/api_body.$$
# _call sets CODE and writes the body to $BODY; on 401 it logs in again once
```

> ⚠️ **`st-env.sh` 占用了变量名 `PW`、`B`、`T`、`BODY`、`CODE`**（以及函数名 `login`、`_call`、`api`、`api_code`、`psql_c`、`hyper_uuid`）。自己的脚本里**别用这些名字做变量**，否则之后的请求全部返回 000（2026-09-28 放置组测试踩过）。

- **token 有效期 120 分钟**。登录不会吊销别的会话的 token；`switch-org` / `switch-region` 只吊销调用者自己的旧 token。`st-env.sh` 遇 401 自动重登，`alarmtest-env.sh` 要手动重新 `source`。
- **列表接口默认只回 50 条**，取全量带 `limit`（如 `?limit=500`）；云硬盘另加 `type=all`，否则只列数据盘。

### 引号陷阱

经 `ssh work-01 '...'` 传一层引号时，`api POST` 的 JSON 里嵌套引号极易炸。**请求体一律写成文件再 `-d @file`**：

```bash
cat > /tmp/body.json <<'JEOF'
{"hostname":"wp-vm","image":{"id":"..."},"flavor":"vmtest-small"}
JEOF
curl -sk -X POST "$B/instances" -H "Authorization: Bearer $T" -H 'Content-Type: application/json' -d @/tmp/body.json
```

- 本地 Git Bash 的 heredoc 会把 `\\` 吞成一个反斜杠，需要字面反斜杠时用 `printf '\x5c'` 或用编辑器直接写文件。
- 用 `ssh work-01 'bash -s' < 脚本` 执行本地脚本时，脚本里的 `docker exec -i`（包括 `psql_c`）和 `ssh` 会**吞掉后面的脚本**：`docker exec -i ... </dev/null`、`ssh -n`。
- `ssh work-01 '... psql -c "..."'` 里 SQL 的字符串用 `\$\$...\$\$`（单引号会和外层打架；没转义的 `$$` 会被远端 shell 展开成进程号）。
- 一条 `psql -c` 里放多条语句**只打印最后一条的结果**，要分开调用。

### 3.3 ⚠️ 对线上环境做 UI 测试必须兜底拦截写请求

曾经出过事故：拦截规则写成 `**/api/v1/system/settings`，没匹配到带 `?region=` 的请求，测试脚本真的把 `DNS_UPSTREAM` 改成了 9.9.9.9、默认 CPU 配额从 4 改成 8。

**只读类脚本一律在 context 上加这段兜底**（按 pathname 匹配；只放行登录与切换组织 / 区域、遥测、监控曲线查询）：

```js
// Safety net: abort every non-GET API call except login, org/region switch, telemetry and metric queries
const ALLOW = [/^\/api\/v1\/auth\/(token|switch-org|switch-region)/, /^\/api\/v1\/telemetry\//, /\/his_data$/]
await context.route('**/*', (r) => {
    const req = r.request()
    const p = new URL(req.url()).pathname
    if (req.method() !== 'GET' && p.startsWith('/api/') && !ALLOW.some((re) => re.test(p))) {
        console.log('BLOCKED', req.method(), p)
        return r.abort()
    }
    return r.continue()
})
```

- 挂在 **`context`** 上而不是 `page` 上：控制台等新开的窗口也在拦截范围内。
- （2026-09-28 核对）旧写法放行了所有含 `/metrics/` 的路径，会把 `/metrics/alarm/{cpu,memory,bw}/rules`、`/metrics/alarm/link` 这些**建告警规则 / 关联虚拟机**的写请求放过去；现在只放行 `.../his_data` 曲线查询。

写入类用例（本套件里明确标注「建资源」的）才允许放开，且只对本用例要写的路径放开（往 `ALLOW` 里加一条，如 `/^\/api\/v1\/placement_groups/`），资源名用本轮前缀。

```bash
  | awk -F'\t' '$1 !~ /^120000/ {split($1, a, " "); print a[3], $2}' > <临时目录>/wp-tree.txt
# work-01: hash of the file on disk, raw bytes
ssh work-01 'cd /opt/cloudland; while read -r h p; do
  [ -f "$p" ] || { echo "MISSING $p"; continue; }
  [ "$(git hash-object --no-filters "$p")" = "$h" ] || echo "DIFF $p"; done' < <临时目录>/wp-tree.txt
```
