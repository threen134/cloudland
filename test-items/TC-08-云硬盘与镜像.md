# TC-08 云硬盘与镜像（VOL）

优先级 **P1** · 会创建卷与镜像 · 约 25 min

## 设计约定 — 本地数据卷

- **创建时不落盘**：`volumes.hyper=0`，path `volume-<id>.disk`，直接 `available`
- **首次挂载时**才由 `attach_volume_local.sh` 按大小在**虚拟机所在节点**创建，并记录 `hyper`
- 已落盘的卷**只能挂给同节点的虚拟机**
- 删除 / 未挂载扩容按 `hyper` 下发；未落盘时只改记录
- 迁移完成后随虚拟机更新 `hyper`
- 删除虚拟机时卷变 `available`、`instance_id` 清空，**卷文件保留**

> `GET /volumes` 默认**只列数据盘**，要含系统盘得带 `type=all`。配额对账用的是 `type=all`。

## VOL-01 创建与挂载

**P1**

```bash
ssh work-01 'source /root/alarmtest-env.sh
cat > /tmp/v.json <<JEOF
{"name":"wp-vol","size":5}
JEOF
V=$(curl -sk -X POST "$B/volumes" -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d @/tmp/v.json | jq -r .id)
echo "卷=$V"
api GET /volumes/$V | jq -c "{name,size,status,hyper}"

I=$(api GET /instances | jq -r ".instances[]|select(.hostname==\"wp-vm\")|.id")
cat > /tmp/a.json <<JEOF
{"instance":{"id":"$I"}}
JEOF
curl -sk -X PATCH "$B/volumes/$V" -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d @/tmp/a.json | jq -c "{name,size,status}"
sleep 15; api GET /volumes/$V | jq -c "{name,status,hyper,target}"'
```

### 检查项

- [ ] 创建后直接 `available`，`hyper=0`（未落盘）
- [ ] 挂载后 `status` 经 `attaching` → `in_use`
- [ ] 挂载后 `hyper` 变成虚拟机所在节点的 hostid
- [ ] 节点上出现磁盘文件
  ```bash
  ssh work-0X 'ls -la /opt/cloudland/cache/volume/ | grep <卷 id 前 8 位>'
  ```
- [ ] 实例详情的 `volumes` 数组里这一项**带 `size`**
- [ ] 盘符是下一个空闲 vdX
  > **回归点**：第二块本地数据卷曾总是分到 vdb（原按 WDS 的 `type='network'` 计数）。挂第二块时确认是 **vdc**。

## VOL-06 镜像导入

**P1**

```bash
ssh work-01 'source /root/alarmtest-env.sh
cat > /tmp/img.json <<JEOF
{"name":"wp-img","download_url":"http://<可达地址>/cirros-0.6.2-x86_64-disk.img",
 "os_code":"cirros","os_family":"linux","os_version":"0.6.2","user":"cirros","boot_loader":"bios"}
JEOF
curl -sk -X POST "$B/images" -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d @/tmp/img.json | jq -c "{id,name,status}"'
```

必填：`name` / `download_url` / `os_code` / `os_family` / `os_version` / `user` / `boot_loader`。

- [ ] 创建后状态经 `pending` → `available`
- [ ] 格式自动识别正确（qcow2 / raw）
- [ ] `available` 后能用于创建虚拟机

### URL 校验

```bash
for bad in "http://x/a b.img" "http://x/a$(printf '\n')b" "http://x/a -o /root/.ssh/authorized_keys"; do ... done
```

- [ ] `download_url` **禁止空白与控制字符**，非法返回 400
  > **回归点**：`http_url` 校验允许空格，曾可拼出 `curl ... -o /root/.ssh/authorized_keys`。见 `TC-13 SEC-02`。

## 清理

```bash
ssh work-01 'source /root/alarmtest-env.sh
for v in $(api GET "/volumes?type=all" | jq -r ".volumes[]|select(.name|startswith(\"wp-\"))|.id"); do
  api PATCH /volumes/$v "{}" >/dev/null; sleep 3; api DELETE /volumes/$v >/dev/null
done
for m in $(api GET /images | jq -r ".images[]|select(.name|startswith(\"wp-\"))|.id"); do api DELETE /images/$m >/dev/null; done
api GET "/volumes?type=all" | jq -r ".volumes[].name"; api GET /images | jq -r ".images[].name"'
```

- [ ] 无 `wp-` 残留
- [ ] 保留镜像 `cirros-0.6.2`、`ubuntu-24.04-minimal` 完好
